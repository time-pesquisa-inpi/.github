# Time Pesquisa INPI · CEIA/UFG 👋

Time de pesquisa e capacitação do projeto de **IA para exame de marcas** desenvolvido pelo CEIA/UFG para o INPI.

### 🚀 PoC atual
**[Detector de Impeditivos](https://github.com/time-pesquisa-inpi/detector-impeditivos)**: recebe o nome e o logo de uma marca e aponta possíveis impedimentos do art. 124 da LPI: termos proibidos no texto e bandeiras, brasões ou símbolos oficiais na imagem, com um VLM local.

> Este espaço usa apenas dados públicos ou fictícios. Nenhum dado interno do INPI é publicado aqui.
